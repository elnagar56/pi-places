# Pi Places - دليل الأماكن الداعمة لـ Pi

تطبيق ويب تقدمي (PWA) يهدف إلى مساعدة أعضاء مجتمع Pi Network في اكتشاف المتاجر والخدمات التي تقبل الدفع بعملة Pi وإضافة أماكن جديدة بسهولة.

## النسخة الحية المباشرة
https://elnagar56.github.io/pi-places

## أبرز المميزات
- واجهة عربية سريعة ومتجاوبة مع شاشات الموبايل.
- إمكانية التثبيت على الشاشة الرئيسية للموبايل كتطبيق ويب تقدمي (PWA).
- دعم التخزين المؤقت عبر Service Worker لسرعة التحميل.
- إمكانية إضافة أماكن جديدة وتصنيفها وتصفيتها بسهولة.

## طريقة التثبيت على الموبايل
1. افتح الرابط المباشر للتطبيق في متصفح Chrome على الموبايل.
2. افتح قائمة المتصفح (الثلاث نقاط) واختر **إضافة إلى الشاشة الرئيسية** أو **تثبيت التطبيق**.
